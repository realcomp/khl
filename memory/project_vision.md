Проект работает по модели **freemium** с двумя целевыми аудиториями:

1. **Болельщики (free)** — статистика, история, протоколы матчей, сравнения игроков
2. **Тренеры и скауты (premium)** — профильный поиск игроков, бенчмарки, межлиговые сравнения

**Why:** Данные и инфраструктура (межлиговые коэффициенты, возрастные группы, похожие игроки) уже построены с прицелом на скаутский инструментарий. Не хватает UI для составления сложных запросов.

**Ключевые сценарии для скаутов:**
- «Покажи свободных нападающих с правым хватом, 2001–2004 г.р., с показателями не хуже X»
- «Найди игрока, чьи показатели в МХЛ в его возрасте не хуже, чем у Радулова в аналогичный период, допущение 80%»

**Ключевой сценарий для тренеров — радарная диаграмма команды:**
1. Радар текущей команды по осям (результативность, физика, оборона, большинство, вбрасывания, вратари, дисциплина)
2. Наложение целевого профиля (другая команда / топ-5 / кастом) → провалы подсвечены
3. Клик на провал → атрибуция: какие конкретные игроки тянут этот показатель вниз
4. Из того же экрана — поиск замены среди свободных агентов и ВХЛ/МХЛ с нужным профилем
Весь цикл диагностика → атрибуция → замена — в одном интерфейсе.

**How to apply:** При предложении новых фич — в первую очередь смотреть на ценность для скаутов/тренеров как на монетизируемый Premium-слой. Межлиговые коэффициенты и сравнение по возрасту — уже реализованы, нужен интерфейс поверх них.
