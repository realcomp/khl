# Описание проекта Sportomatics KHL

## Что это за проект

**Sportomatics KHL** — платформа аналитики и статистики российского профессионального хоккея в формате **freemium**. Охватывает три лиги: **КХЛ** (Континентальная), **ВХЛ** (Высшая), **МХЛ** (Молодёжная). Сайт доступен на `khl.sportomatics.com`, на русском и английском языках.

### Две целевые аудитории

| Аудитория | Модель | Что нужно |
|---|---|---|
| **Болельщики** | Free | Статистика, история клуба, протоколы матчей, сравнения |
| **Тренеры и скауты** | Premium | Поиск игроков по профилю, бенчмарки, межлиговые сравнения |

Ключевая ценность для профессионалов — **профильный поиск игроков**: «найди мне свободного нападающего с правым хватом, 2001–2004 г.р., с показателями не хуже X» или «найди игрока, чьи показатели в МХЛ в его возрасте не хуже, чем у Радулова в аналогичный период, допущение 80%».

## Что видит пользователь

### Игрок — полный профиль

Каждый игрок имеет подробную карточку:

- **Биография**: полное имя (рус/англ), дата и место рождения, гражданство, возраст, рост, вес, хват клюшки
- **Карьера**: все клубы с точными датами, лига каждого сезона
- **Контракт**: тип, дата окончания, текущий клуб
- **Социальные сети**: ВКонтакте, ОК, Facebook, Twitter, Instagram, YouTube, Wikipedia, личный сайт
- **Фотогалерея**: фото подтягиваются из Instagram

**Статистика полевого игрока:**
- Матчи, голы, передачи, очки, +/−, штрафные минуты
- Голы по типу: в большинстве, в равных составах, в овертайме, победные, буллиты
- Точность бросков (%)
- Вбрасывания: выиграно, % побед
- Хиты, блоки, нарушения за период

**Статистика вратаря:**
- Отражённые броски, % отражений
- Пропущенные голы, коэффициент надёжности
- Сухие матчи, победы/поражения

---

### Команда — полная страница клуба

- **Информация**: дата основания, цвета клуба (3 цвета), логотип, официальный сайт, email, телефон
- **Состав**: игроки по позициям (вратари, защитники, нападающие) с номерами
- **Тренерский штаб**: главный тренер и ассистенты с датами работы
- **Арена**: вместимость, адрес, координаты, ссылка на билеты
- **Аффилиаты**: фарм-клуб и юниорская команда
- **История адресов**: где играла команда по сезонам
- **Соцсети**: официальные страницы команды

---

### Матч — подробный протокол

Каждая игра содержит:
- Дата, время, лига, тип (чемпионат / плей-офф / турнир), количество зрителей
- Счёт по периодам, был ли овертайм или буллиты
- **Хронология голов**: кто забил, кто ассистировал, время, тип гола (ОШ/ЧБ/БМ/буллит), составы (5 на 5 или другие)
- **Хронология штрафов**: игрок, тип нарушения, время, длительность
- **Статистика каждого игрока** в этом матче: голы, передачи, +/−, штраф, броски, время на льду, вбрасывания
- Официальные лица: главные и линейные судьи

---

### Аналитика и сравнения

**Сравнение игроков:**
- Выбор нескольких игроков и сравнение всех метрик «лицом к лицу»
- Визуальные графики для наглядного сопоставления
- **Межлиговые поправочные коэффициенты**: чтобы сравнить игрока из МХЛ с игроком из КХЛ честно (с понижающим коэффициентом 0.8× за каждый уровень лиги)
- Сравнение по возрастным группам: юниоры, молодёжь, опытные, ветераны

**«Похожие игроки»:**
- Для каждого игрока система вычисляет статистически похожих хоккеистов (по голам, передачам, очкам, штрафу, +/−)

**Партнёры:**
- С кем игрок чаще всего выходил на лёд, насколько продуктивным было это сочетание

**Ранжирование:**
- Игроки проиндексированы по всем показателям — можно видеть место игрока в рейтинге лиги/команды

# Чего не хватает — предложения по развитию

## Блок 1 — Инструментарий для тренеров и скаутов (Premium-ядро)

Это главная нереализованная ценность проекта. Данные и инфраструктура (межлиговые коэффициенты, возрастные группы, похожие игроки) уже есть — не хватает **пользовательского интерфейса для составления запросов**.

### Радарная диаграмма команды — инструмент тренера

Полный воркфлоу от диагностики до подбора замены:

**Шаг 1 — Профиль команды на радаре**
Тренер видит свою команду в виде радарной диаграммы по ключевым осям:
- Результативность (голы/матч)
- Передачи / созидание
- Физическая игра (хиты/матч)
- Оборонительность (блоки, +/−)
- Большинство / меньшинство (% эффективности)
- Вбрасывания (% побед)
- Надёжность вратарей (% отражений)
- Дисциплина (штрафные минуты/матч)

**Шаг 2 — Наложение целевого профиля**
В качестве цели тренер выбирает:
- Конкретную команду КХЛ («хочу играть как ЦСКА»)
- Среднее значение топ-5 команд лиги
- Собственный кастомный профиль (задать значения вручную)

Провалы — зоны, где текущая команда не дотягивает до цели — **подсвечены красным на радаре**.

**Шаг 3 — Кто виноват в провале**
Тренер кликает на ось с провалом → система показывает, **какие конкретные игроки «тянут вниз»** этот показатель. Например, по оси «физическая игра» провал делают три нападающих с минимальным количеством хитов.

**Шаг 4 — Подбор замены**
Прямо из этого экрана тренер запускает поиск: «найди мне нападающего, который закроет этот провал» — система предлагает кандидатов из свободных агентов и игроков ВХЛ/МХЛ с нужным профилем. Межлиговые коэффициенты применяются автоматически.

> Весь цикл — диагностика провала → атрибуция игроку → замена — происходит в одном интерфейсе, без переключения между страницами.

---

### Конструктор профиля игрока — инструмент скаута
Скаут задаёт параметры и получает список кандидатов:
- Позиция (нападающий / защитник / вратарь)
- Хват клюшки (левый / правый)
- Год рождения (диапазон)
- Лига (КХЛ / ВХЛ / МХЛ)
- Статус контракта (свободен / контракт истекает / под контрактом)
- Гражданство
- Пороговые значения по любой метрике (голы ≥ X, +/− ≥ Y, % отражений ≥ Z)

### Поиск по бенчмарку («как Радулов в его возрасте»)
Выбрать эталонного игрока → система берёт его статистику в заданном возрасте и лиге → ищет всех текущих игроков того же возраста с похожими показателями → выдаёт список с процентом совпадения.
- Допущение задаётся пользователем (например, 80% = показатели не хуже, чем 80% от эталона)
- Межлиговые коэффициенты применяются автоматически — МХЛ-игрок честно сравнивается с КХЛ-игроком

### Фильтр «свободные агенты»
Отдельная витрина игроков без действующего контракта или с истекающим контрактом в текущем сезоне. Ключевой инструмент перед трансферным окном.

### Шортлист / избранное
Тренер или скаут отмечают кандидатов, формируют список для презентации руководству клуба. Сохраняется в аккаунте.

### Экспорт
PDF или CSV с карточками выбранных игроков — для презентации на тренерском совете.

## Блок 2 — Матч-превью для думающего болельщика (и для ставок)

Отдельный продуктовый слой: страница предстоящего матча, которая даёт **аналитический контекст**, а не просто вывеску. Все данные уже есть в базе — нужна витрина.

### Наложение радаров двух команд
Радарные диаграммы обеих команд совмещены на одном графике. Сразу видно, где у одной команды явное преимущество, где паритет, где она уступает. Не «кто фаворит по турнирной таблице», а **где именно проходит силовая граница конкретного матча**.

### Коэффициент состава — «та же команда?»
Головная боль head-to-head статистики — за 3 года состав мог полностью смениться, и прошлые встречи нерелевантны. Решение: для каждого исторического матча между этими командами система считает **% пересечения нынешнего состава с составом той игры** (по суммарному игровому времени, не по числу игроков).

Пример: «последние 10 встреч Спартака и Динамо. Сегодняшний Спартак на 74% совпадает с тем, кто играл в этих матчах. Динамо — на 89%.» Это означает, что статистика встреч достаточно релевантна. Если бы совпадение было 30% — предупреждение: «составы кардинально изменились, история нерелевантна».

### Тренд команды — на подъёме или спаде
Не просто «выиграли 3 из 5», а динамика по нескольким осям за последние N матчей:
- Голы забитые/пропущенные в каждом из последних матчей (столбчатый мини-график)
- Тренд вратаря: % отражений за последние 5 игр
- Тренд результативности топ-бомбардира

### Фактор домашнего/выездного матча
Сколько побед дома vs. в гостях в этом сезоне — с конкретными цифрами. «СКА дома выигрывает в 78% случаев, в гостях — в 52%». Один из самых надёжных предикторов в хоккее.

### Фактор усталости
Сколько дней прошло с последней игры у каждой команды. Играет ли команда второй матч за 48 часов («back-to-back»). Сколько выездных матчей подряд. Данные по расписанию уже есть.

### Матч-ап по специальным бригадам
Если одна команда — лучшая в лиге по большинству, а другая — худшая по меньшинству, это фактор. И наоборот. Точечный срез: **эффективность большинства хозяев vs. эффективность меньшинства гостей**.

### «Немезис»-эффект
Некоторые команды исторически играют выше своего уровня именно против конкретного соперника — независимо от таблицы. «Локомотив против ЦСКА выигрывает в 58% случаев, хотя в среднем по сезону — в 44%». Статистически интересный факт и хороший аргумент для ставки против фаворита.

### Показатель напряжённости матча
Сколько в среднем голов забивается в играх между этими командами, как часто уходят в овертайм/буллиты. Косвенно говорит о том, стоит ли ставить на тотал «меньше» или «больше», и насколько реален исход в три периода.

## Блок 4 — Контент для болельщиков (Free-уровень)

### Турнирная таблица
Первое, что ищет болельщик. Данные уже есть в матчах — нужно только агрегировать очки, разницу голов, форму последних 5 матчей.

### Серии (стрики)
«Забивает в 8 матчах подряд», «команда не проигрывала 12 игр» — живой контент, возвращающий пользователей каждый день. Вычисляется из существующих данных о матчах.

### Плей-офф сетка
Bracket с текущим счётом серий. В плей-офф — главная навигация болельщика.

### Вехи и рекорды на главной
«Сегодня Ковальчук сыграл 800-й матч в КХЛ» — система данных это позволяет вычислить, осталось только отображать на главной странице рядом с днями рождений.

### All-time рекорды лиги
Зал рекордов: кто больше всех забил за историю КХЛ, лучший вратарский сезон, рекорды серий. Витрина над существующими данными.

## Блок 5 — Аналитика (данные есть, среза нет)

### Домашний / выездной сплит
Как команда или игрок выступают дома vs. в гостях. У некоторых клубов разница принципиальная — интересный факт сам по себе.

### Специальные бригады
Эффективность большинства и меньшинства по командам и игрокам. Сейчас зарыто внутри матчей, но нет агрегированного среза «лучшие бригады большинства лиги».

### Форма команды — последние N матчей
Динамика: средний счёт, % побед, тенденция.

### Голкиперы: нагрузка vs. результат
Среднее количество бросков за матч vs. % отражений. Важно для скаутов, интересно для болельщиков.

### Контекст по возрасту (Age Curve)
«Капризов в 23 года забил X голов — лучший показатель среди 23-летних за 10 лет». Популярный формат у аналитиков, хорошо расшаривается.

---

## Блок 6 — Судейская аналитика

Судьи уже присутствуют в каждом протоколе матча — эти данные не используются совсем.

### Профиль арбитра
Сколько штрафов в среднем назначает конкретный судья за матч, как это соотносится со средним по лиге, как влияет на темп игры и итоговый счёт. Страница каждого арбитра с историей матчей.

### Баланс штрафов
Какой % штрафов в матчах под конкретным арбитром назначается хозяевам vs. гостям — есть ли систематический перекос в пользу домашней команды.

### Судья как фактор матч-превью
«В этом матче судит X. Под его свистком команды в среднем получают 8 штрафов за игру и забивают 5+ голов» — прямой аргумент для ставки на тотал. Данные для этого полностью есть в базе, нигде в КХЛ не публикуется.

## Блок 7 — Аналитика пятёрок и звеньев

В протоколах матчей хранится, кто находился на льду при каждом голе (состав пятёрки). Из этого можно извлечь командную аналитику, которую не даёт индивидуальная статистика.

### Продуктивность сочетаний нападающих
Какие тройки / пары нападающих статистически наиболее эффективны вместе — по голам, по +/−, по времени на льду. «Иванов хорош, но именно с Петровым, а с Сидоровым — нет».

### Надёжность пар защитников
Какие пары защитников дают лучший +/− и допускают меньше голов при нахождении на льду.

### Слабые пятёрки
Сочетания, которые пропускают непропорционально много — «пятёрка смерти». Тренеру важно знать это до того, как счёт станет 0:3.

## Блок 8 — Влияние ключевого игрока

«Что происходит с командой, когда X не играет?»

Все матчи, где игрок отсутствовал (травма, дисквалификация, вызов в сборную), уже есть в базе — достаточно проверить протокол на наличие игрока в составе.

- Сравнение показателей команды «с игроком» и «без игрока»: % побед, голы забитые/пропущенные
- «ЦСКА с Федотовым — 78% побед. Без него — 51%»
- Для скаутов: аргумент при оценке реальной ценности игрока для клуба
- Для болельщиков: объяснение, почему команда «вдруг» просела

---

## Блок 9 — Пульс сезона: автоматические инсайты

Алгоритмически генерируемые факты, которые обновляются после каждого тура. Никаких новых данных — только алгоритм поверх существующих.

### Примеры инсайтов
- «Это самая результативная игра сезона» — после конкретного матча
- «Петров забивает в 6-м матче подряд — личный рекорд карьеры»
- «При таком темпе Шипачёв финиширует с 71 очком — лучший результат за 5 лет»
- «Локомотив не проигрывал дома 14 матчей подряд»
- «У СКА лучшая защита последних 10 туров — 0.8 гола за матч»

### Зачем это нужно
Это **контент-машина**: каждый тур автоматически генерирует 10–15 таких фактов. Они хорошо расшариваются в Telegram и соцсетях, привлекают аудиторию без редакционных усилий. Фактически это бесплатный маркетинг.

## Блок 10 — Рыночная ценность игрока

КХЛ не публикует зарплаты, но **относительную оценку** можно построить из существующих данных.

### Синтетический показатель ценности
Регрессионная модель по статистике, возрасту, лиге и позиции — типичная «стоимость» игрока с такими показателями на рынке. Не абсолютная цифра в рублях, а **индекс** (100 = средний КХЛ-игрок на этой позиции).

### Динамика ценности
График: как рыночная ценность игрока менялась год от года. Виден пик карьеры, спад, неожиданный рост после смены клуба.

### Переоценённость / недооценённость
«Этот игрок по показателям соответствует уровню среднего КХЛ-защитника, но играет в ВХЛ — потенциально недооценён». Для скаутов — прямой сигнал.

## Блок 11 — Инструмент для агентов

Смежная аудитория, которая пользуется тем же инструментарием, что и скауты, но с другой точкой входа.

### Что нужно агенту
- Шортлист собственных клиентов с актуальной статистикой в одном месте
- Сравнение клиента с аналогами — аргумент в переговорах о контракте («мой игрок статистически на уровне X, который зарабатывает Y»)
- Мониторинг конкурентов: у кого из схожих игроков истекает контракт — потенциальная замена клиенту на его позиции

По сути это тот же Premium-инструментарий скаута, только «навыворот» — скаут ищет игрока для клуба, агент ищет клуб для игрока.

## Блок 12 — B2B API

Все собранные данные ценны не только для прямых пользователей сайта.

### Потенциальные клиенты
- **Спортивные редакции** (Матч ТВ, Sports.ru, Чемпионат) — статистические виджеты на страницах матчей
- **Беттинговые компании** — исторические данные, h2h, судейская аналитика
- **Другие хоккейные сайты** — встраиваемые виджеты (карточка игрока, радар команды)
- **Клубы КХЛ** — белая метка: собственная аналитика для тренерского штаба

### Почему это работает
Данные уже собраны и структурированы. API поверх существующей базы — отдельный revenue stream без изменения основного продукта.

## Блок 13 — Исторический и контекстный контент

### Профили тренеров
Самостоятельные страницы: результаты с каждым клубом, % побед, трофеи. Данные частично есть.

### История наград КХЛ
Кубок Гагарина, индивидуальные награды сезона. Сейчас этого нет совсем.

### Национальный контекст
Статистика игрока на чемпионатах мира / Олимпиадах. Требует внешних данных, но КХЛ и сборная в голове болельщика неразрывны.

### Сравнение команд head-to-head
Как ЦСКА исторически играет против СКА: последние N встреч, кто выигрывает серии, счёт матчей.
